# Module 1: Communication in a Connected World

## (1.1) Network Types

### What is the internet?

- The **internet** is a worldwide collection of interconnected networks (internetwork or internet), cooperating with each other to exchange information using common standards.

> The internet is **NOT owned by any individual or group.**

### Local Networks

- **Small Home Networks** = connect few computers to each other and to the internet
- **Small Office and Home Office Networks (SOHO)** = allows computers in a home office or a remote office to connect to a corporate network, or access shared resources.
- **Medium to large Networks** = corporations and schools
- **World Wide Networks (internet)** = network of networks

### Mobile Devices

- **Smartphone** = connects to the internet from almost anywhere and combines different functions together such as phone, camera, GPS, touch screen computer, etc.
- **Tablet** = similar to smartphones, but has bigger screen size.
- **Smartwatch** = connects to smartphones and provides additional functions like pedometer.
- **Smart Glasses** = glasses with tiny screen that displays information

### Connected Home Devices

- **Security System** = security systems, lighting, and climate controls that can be monitored and configured remotely using a mobile device
- **Appliances** = fridges, ovens, and dishwashers can be connected to the internet, like the security system where these can be controlled remotely using a mobile device.
- **Smart TV** = connected to the internet without TV service provider equipment
- **Gaming Console** = connect to internet to download games

### Other Connected Devices

- **Smart Cars** = modern cars can be connected to the internet and able to connect to other devices.
- **RFID Tags** = Radio Frequency Identification (RFID) tags can be placed in/on objects
- **Sensors and Actuators** = sensors provide temp, pressure, humidity, wind speed, etc. and Actuators can then be automatically trigged based on current conditions.
- **Medical Devices** = pacemakers, insulin pumps, and hospital monitors provide feedback/alerts.
